# AI-диагност ПК и сети

Локальная утилита для Windows: собирает снимок системы, выполняет
безопасные диагностические команды, отправляет вывод в LLM и
получает понятный вердикт — что сломано и что делать.

## Что делает

- Два режима: **Быстрая** (10 пакетов, ранний выход) и
  **Полная** (50 пакетов, MTU-тест, без раннего выхода).
- Сбор baseline: ОС, интерфейсы, IP, шлюз, DNS, права.
- Каскад проверок: шлюз → 8.8.8.8 → 77.88.44.242 → tracert.
- Анализ через OpenAI (`gpt-4o-mini`).
- Логи в `log.jsonl`, лимит 1000 записей, авто-вытеснение.
- Просмотр последнего прогона, очистка логов.

## Что НЕ делает

- Не выполняет команды, предложенные ИИ.
- Не запускает опасные команды (`route -f`, `netsh winsock reset`).
- Не работает без API-ключа OpenAI (анализ будет fallback).

## Установка

    pip install -r requirements.txt
    cp .env.example .env
    # впиши OPENAI_API_KEY

## Запуск

    streamlit run app.py

Браузер откроется на `http://localhost:8501`.

## Тесты

    pip install -r requirements-dev.txt
    pytest tests/ -v

## Структура

    core/       — логика проверки
    history/    — логирование
    ui/         — рендеринг
    tests/      — тесты

## Безопасность

- Белый список команд, никакого `shell=True`.
- Валидация IP, домена, имени интерфейса.
- ИИ не выполняет команды напрямую.
- Логи в `%APPDATA%\ai-diagnost\logs\`.

## Ограничения MVP

- Windows-only.
- Полноценно работают два интента: `internet_down`, `site_unreachable`.
